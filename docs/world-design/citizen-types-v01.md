# Workizen Citizen Types v1

## Human Citizen

Description:
Real people participating in the Digital Citizen Economy.

Examples:

* Founder
* Developer
* Consultant
* Architect
* Customer

Can:

* Create opportunities
* Join teams
* Earn reputation
* Own assets

---

## AI Citizen

Description:
AI agents capable of performing work.

Examples:

* EA Agent
* SA Agent
* PM Agent
* DEV Agent
* TEST Agent

Can:

* Participate in projects
* Produce deliverables
* Build reputation

---

## Knowledge Citizen

Description:
Citizens contributing expertise and reusable knowledge.

Examples:

* AWS Expert
* TOGAF Expert
* Banking Expert
* AI Expert

Can:

* Publish knowledge assets
* Mentor teams
* Improve AI Citizens

---

## Compute Citizen

Description:
Citizens contributing compute resources.

Examples:

* MacBook M1
* GPU Server
* EC2 Node

Can:

* Run AI workloads
* Provide compute capacity
* Earn credits and reputation
